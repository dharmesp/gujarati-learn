# Gujarati Match & Learn: publishing

**Live game:** https://dharmesp.github.io/gujarati-learn/
**Code:** https://github.com/dharmesp/gujarati-learn

## Put it on the child's phone

1. Open **https://dharmesp.github.io/gujarati-learn/** on the phone, with internet on.
2. Install it:
   - **iPhone / iPad:** use **Safari** → Share button (square with arrow) → **Add to Home Screen** → Add.
   - **Android:** use **Chrome** → ⋮ menu → **Install app** (or **Add to Home screen**).
3. From now on, open the game **from the new icon** ("Gujarati Learn").

## Updating the game later

After changing files in this folder, open a terminal here and run:

```
git add .
git commit -m "Describe the change"
git push
```

(Or just ask Claude: "commit and push my changes".)

GitHub updates the website in about a minute. On the phone, open the app once
with internet; the new version appears the **next** time it is opened. Progress is kept.

## Good to know

- Works offline after it has been opened once with internet.
- Progress lives on the phone. A different phone or browser starts fresh.
- On iPhone, the Home Screen app and Safari keep **separate** progress. Always use the icon.
- Parents area: home screen → **⚙️ For parents** (answer a small sum). Reset, clear data,
  or choose which letter to start from.
